# 규정 정비 후보 (AI 검토 결과, 담당부서 확인 전)

작성 2026-10-21. 문답 카드를 만들면서 AI가 규정 원문을 읽다가 발견한 오기, 잘못된 조문 인용, 규정 사이 충돌, 상위 법령과 다른 점입니다. 모두 **후보**이며 담당부서가 확인해야 합니다.

- 전체 330건, 68개 규정
- ✔ 257건: 지적한 문구가 규정 원문에 실제로 있음을 프로그램으로 확인했습니다. 고칠 방향이 맞는지는 확인하지 않았습니다.
- △ 73건: 따옴표로 짚은 문구가 없거나 원문과 글자가 달라 자동 확인을 못 했습니다.
- 상위 법령과 비교한 건은 아래 "법령 대조" 절에 따로 적었습니다.
