# 평가단 종합 판정 (2026-10-21)

질문: 지금까지 만든 내규챗봇 시범본이 직원들이 만족할 만큼 쓸 수 있는 완성품인가?

평가자 4명이 서로의 결과를 보지 않고 따로 평가했다. 실패 사례 중 일부는 종합하면서 직접 다시 돌려 확인했다.

| 평가자 | 무엇을 했나 | 핵심 결과 | 점수(5점 만점) |
|---|---|---|---|
| 직원 사용자 | 카드를 보지 않고 직원 말투 질문 50개 | 만족 58%, 보통 24%, 불만 18%. 틀린 답을 '바로 답'으로 낸 경우 4건 | 정확성 4, 찾기 쉬움 3, 읽기 쉬움 4, 만족도 3.5 |
| 담당부서 검수자 | 무작위 카드 45장을 원문과 뜻 단위로 대조 | 중대한 오류 0, 사소한 누락 7(16%). 숫자·기한·결재권자 오류 0 | 사실 정확성 5, 누락 위험 4, 근거 신뢰성 5 |
| 복잡한 질문 | 여러 조건·여러 규정·계산·이어 묻기 25개 | 충분 5, 부분 15, 실패 5 | 단순 질문 4, 복잡한 질문 2, GPTs 대체 2 |
| 운영·보안·AI 규정 | 배포, 유지보수, 인공지능전환관리세칙 대조 | 외부 글꼴 호출로 폐쇄망에서 멈출 수 있음, IE 모드 불가, 개정 감지 장치 없음, 세칙 절차 미이행 | 배포 3, 유지보수 2, 규정 준수 2 |

## 판정

**완성품은 아니다. "시범 운영(베타)"으로 소수에게 열어 볼 수준이다.**

- 답의 내용(정확성·근거)은 정식 서비스 수준이다. 맞는 카드가 나오면 숫자·기한·결재권자가 원문과 일치하고, 모든 답에 원문이 연결된다. GPTs보다 나은 점이다.
- 찾기는 아직 부족하다. 평소 말투로 물으면 다섯 번에 한 번꼴로 엉뚱한 답이 나오고, 그중 일부는 확신 있게 틀린다. 직원 신뢰를 가장 크게 깎는 부분이다.
- 복잡한 질문(조건 여러 개, 규정 두 개 이상, 개인 계산, 이어 묻기)은 원리적으로 못 한다. 처음 목표였던 "GPTs 대체"는 단순 조회 범위에서만 이룬 셈이다.
- 운영 체계가 없다. 사람 검수 0건, 규정 개정 감지 장치 없음, 관리자 1명·장비 1대, 세칙상 절차(세부실행과제 확정, 위험평가, 오류신고 창구) 미이행.

## 고칠 순서

### 1단계: 바로 고칠 것 (코드·카드 수정, 하루 안)
1. 외부 글꼴 호출 삭제(폐쇄망에서 최대 2분 넘게 멈춤). 지원하지 않는 브라우저(IE 모드)에 안내 문구.
2. "독립 검증 통과" 초록 표시를 "AI 작성 · 담당부서 검수 전"으로 바꾸고, 검수 메모·정비 후보는 직원 화면에서 접어 두거나 관리자용으로 분리.
3. 검색 보강: 띄어쓰기 없는 말("연차몇일이야"), 반말 어미, 일상어("챗지피티", "근무평정", "폭언"), 질문 속 날짜·숫자 제거. 겹친 글자가 적은데 확신 있게 답하는 경우를 줄임.
4. 맞는 카드가 없을 때 "내규에 직접 규정이 없을 수 있음, 담당부서 문의" 안내.
5. 평가에서 나온 카드 누락 수정: 승진 소요기간(육아휴직 합산), 연가 출근율(휴직 비례 삭감), 인사위원회 구성(외부위원 요건), 인권침해 긴급구제(주체), 전문위탁교육(원장 인정 예외) 등.

### 2단계: 운영 체계 (사람과 절차가 필요, 1~2주)
6. 개정 감지: 카드가 인용한 조문 원문을 저장해 두고, 규정 파일이 바뀌면 원문이 달라진 조문을 인용한 카드를 자동으로 "재검수 필요"로 표시.
7. 담당부서 검수: 위험이 큰 분야(휴가·휴직, 징계·인사위원회, 괴롭힘·성희롱·인권, 계약직)부터. 카드마다 검수자·날짜 기록.
8. 세칙 절차: 위험 수준 자체평가, AX 실무협의회 세부실행과제 확정, 정보보안 검토(claude.ai 게시 포함), 오류신고 창구와 처리 담당 지정, 분기 점검.

### 3단계: 복잡한 질문 (선택)
9. 기존 GPTs 대화에서 질문만 모아 실제 질문 유형 비율을 재고, 자주 나오는 조합으로 "조합 카드" 50~100장 추가.
10. 인터넷망에만 AI 층: 기존 ChatGPT(GPTs·프로젝트)에 이 카드 묶음을 지식으로 넣고 "카드 근거만 쓰고 카드 번호를 대라"고 지시. 폐쇄망은 지금 방식 유지.

## 2단계 중 개정 감지 장치 (2026-10-21)

- `scripts/check_changes.py`: 카드를 확인한 시점의 조문·항·별표·부칙 원문 지문(`knowledge/source_snapshot.json`)과 새 원문을 비교해, 인용한 조·항이 바뀐 카드를 "다시 확인할 카드"로 뽑고 바뀐 글자를 보여 준다(`reports/change_report.md`).
- 화면: 확인 전 카드에 "규정 개정 · 재검수 전"과 바뀐 조문, 위 안내 줄에 개수, 최근 개정 시행일, 만든 지 90일이 지나면 최신판 확인 안내.
- 시험(규정 DB 사본에 개정을 흉내 냄): 복무세칙 제19조 ⑧항에 단서 추가, 여비 별표 금액 변경, 동호회운영지침 제13조 삭제, 제19조의2 신설 → 다시 확인할 카드 8장(⑧항 인용 1, 별표 인용 5, 삭제 조문 인용 2), 같은 조 다른 항 인용 21장은 참고, 신설 조문 1개를 정확히 찾음. 화면 표시도 확인.

## 나머지 단계 반영과 2차 평가 (2026-10-22)

**2단계 준비(사람이 할 일을 바로 시작할 수 있게)**
- 담당부서 검수표 12개(`reports/review/검수표_<분류>.xlsx`, 카드 1,034장, 우선 검수 585장)와 반영 도구(`scripts/review_workbook.py import`). '정확' 카드는 화면에 "담당부서 검수 완료 · 날짜 · 부서", 내용이 바뀌면 자동으로 검수 전으로.
- 오류 신고 창구 설정(`knowledge/site.json`): 운영부서·메일을 적으면 답마다 "메일로 보내기". 지정 전에는 지정 전이라고 안내. 기록이 남지 않던 '도움이 됐어요' 버튼은 뺌.
- 인공지능전환관리세칙 절차 문서 초안(한글): `reports/governance/세부실행과제_제안서.hwpx`(제18조), `위험평가_운영관리방안.hwpx`(제24·25·29~32조). ○○ 자리(부서·담당자·이용료)만 채우면 된다.

**3단계(복잡한 질문)**
- 여러 규정 종합 카드 24장(출산~복직, 배우자 출산, 육아휴직 후 복직, 병가 소진, 경조사, 결혼, 연말 연가, 휴직 중 복무, 국내·국외 출장, 수의계약, 법인카드, 입사, 퇴직, 임금피크, 초과근무, 징계 후, 선물, 외부강의, 겸직, 괴롭힘, 성희롱, 개인정보 유출, 생성형 AI). 근거 대부분은 원문 대조를 마친 단일 카드에서 옮김.
- 화면: 한 질문에 여러 가지를 물으면 나눠 찾은 카드를 함께 보여 줌, "그럼 ~는?" 이어 묻기, 질문 속 날짜를 계산기 맞는 칸에 자동 입력.
- 인터넷망 AI 보조용 지식 묶음(`scripts/export_gpts.py` → `dist/gpts/`, 14개 파일 4.8MB, 지시문 포함).
