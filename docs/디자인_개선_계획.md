# 내규챗봇 디자인 개선 계획

작성 2026-10-22 · 대상 시범본 제1판(dist/index.html) · 도구 ui-ux-pro-max(디자인 시스템·UX 지침 검색) + 화면 실측

**진행 상황**: ① 기본기 완료(2026-10-22). 흐린 글씨 대비 4.66~4.85, 테두리 3.21~3.55, 가장 작은 글씨 12px, 근거 조문 버튼 24px, 체크박스 18px, 계산기 화면 읽기 프로그램 지원, 여는 동안 안내. 화면 점검 54개 통과. ② 첫 화면 정리 완료(2026-10-22, 6장 결정은 권장안대로: 초록 유지, 시범 분야를 '자주 찾는 분야' 10개로 합침, 원문 칸은 근거를 누를 때만 열림, 검증 숫자는 한 줄 요약). 화면 점검 63개 통과. ③·④ 남음.

## 한 장 요약

- **목표**: 직원이 첫 화면에서 무엇을 물을 수 있는지 바로 알고, 답을 읽기 쉽고, 숫자를 잘못 믿지 않게 한다. 기능과 답 내용은 건드리지 않고 겉모양과 쓰기 편함만 고친다.
- **방향**: "FAQ·문서 찾기" 화면 구조. 검색창이 중심이고, 그 아래 자주 찾는 분야, 답, 막히면 담당부서 순서다. 스타일은 미니멀(깨끗하고, 대비가 높고, 기능 위주)이다.
- **4단계**:

| 단계 | 내용 | 걸리는 시간 |
|---|---|---|
| ① 기본기 | 글씨 대비, 글씨 크기, 누르는 크기, 계산기 접근성, 여는 동안 안내 | 반나절~하루 |
| ② 첫 화면 정리 | 분야 메뉴, 오른쪽 빈 칸, 검증 숫자 | 하루 |
| ③ 답 화면 다듬기 | 결론 강조, 휴대폰 표, 계산기 합계 | 하루~이틀 |
| ④ 점검·측정 | 자동 점검 추가, 직원 5초 테스트, 저사양 PC | 반나절 + 사람 |

- **지키는 것**
  - 외부 호출 없이 파일 하나로 둔다.
  - 파일 크기는 늘려도 200KB 안으로 묶는다.
  - 에이투지체를 유지한다.
  - 움직임은 최소로 한다.
  - 색만으로 뜻을 전하지 않는다.

## 1. 지금 화면 진단 (2026-10-22 실측)

### 고쳐야 할 것

### 평가단·자문단이 지적한 사용성 문제

- 주제 버튼 25개 중 14개가 시범 때 만든 '출산·육아', '복무(휴가)'입니다. '규정 전체'와 '상황별로 보기'가 어떻게 다른지 알기 어렵습니다.
- 처음 열었을 때 오른쪽 원문 칸이 비어 있어 화면이 덜 뜬 것처럼 보입니다.
- 아래쪽 검증 숫자 6칸(1034장, 6671/6671 …)은 직원에게 의미가 없고, 관리자에게 필요한 정보입니다.
- 'AI 작성 · 담당부서 검수 전'과 '참고용'이 나에게 무슨 뜻인지, 틀리면 어디에 묻는지 설명이 없습니다.

### 지금 잘 되어 있어 유지할 것

- 답과 근거 원문을 나란히 보는 구조(규정집을 펼쳐 놓은 책상)
- 색을 토큰으로 관리하고, 어두운 화면을 따로 맞춰 둔 것
- 키보드 초점 표시(:focus-visible), 움직임 줄이기 설정(reduced-motion)
- 외부 호출 0, 파일 하나, 에이투지체 내장
- 휴대폰 폭에서 옆으로 넘치지 않음, 휴대폰에서는 원문이 아래에서 올라오는 판으로 열림

## 3. 단계별 계획

### ① 기본기: 읽기·누르기 (반나절~하루, 위험 낮음)

1. 위 표대로 색 토큰을 바꾸고, 입력칸·버튼·체크박스 테두리를 `--line-strong`으로 바꾼다.
2. 글씨 크기
   - 본문은 16px로 올린다.
   - 12px 미만은 없앤다(배지, '확인 필요', 질문 태그를 12px로).
   - 줄 간격 1.6과 답 문단 폭 68자는 유지한다.
3. 누르는 크기
   - 근거 조문 버튼은 최소 높이 24px로 한다.
   - 주제·예시 버튼은 휴대폰 폭(999px 이하)에서 44px로 한다.
   - 버튼 사이 간격은 8px 이상으로 한다.
   - 체크박스는 18px로 하고 이름표 전체를 누를 수 있게 한다.
4. 계산기 접근성
   - 필수 칸에 `aria-required`를 단다.
   - 비어 있는 칸에는 `aria-invalid`를 달고, `aria-describedby`로 '확인 필요' 문구와 연결한다.
   - 결과 영역은 `role="status"`로 한다(계산이 바뀌면 한 번 읽어 줌).
5. 여는 동안 안내
   - HTML 맨 앞에 "내규챗봇을 여는 중입니다(규정 71개·답 1,034개). 사양이 낮은 PC에서는 몇 초 걸릴 수 있습니다." 문구를 둔다.
   - 스크립트가 끝나면 숨긴다. 글자뿐이라 크기는 늘지 않는다.

완료 기준: 자동 점검에서 글씨 대비 4.5 이상·테두리 3 이상, 누르는 크기 24px 이상, 12px 미만 글씨 0개.

### ② 첫 화면 정리 (하루)

1. **위쪽 띠**
   - 제목과 판 번호를 한 줄로 둔다.
   - 신뢰 안내는 한 문장 + '자세히'(누르면 펼침)로 줄인다.
     - 예: "AI가 쓴 답입니다. 근거 원문을 꼭 확인하세요."
     - 펼치면 검수 전·참고용의 뜻과 담당부서 확인 방법이 나온다.
2. **검색창을 화면 중심에**: 입력칸을 크게 두고, 바로 아래에 예시 질문 4개를 둔다.
3. **분야 메뉴**
   - '자주 찾는 분야' 8~10개를 버튼으로 둔다. 예: 휴가·휴직, 출장·여비, 수당·복지포인트, 출산·육아, 인사·평가, 징계·감사, 보안·개인정보, 계약·구매, AI 사용.
   - 나머지는 '모든 분야 보기'를 누르면 펼친다.
   - 시범 분야인 '출산·육아'와 '복무(휴가)'는 '자주 찾는 분야' 안에 합쳐 따로 줄을 차지하지 않게 한다.
4. **오른쪽 빈 원문 칸**: 처음에는 접어 두고 질문 영역을 넓게 쓴다. 근거를 누르면 연다. 대신 첫 화면에 '사용법 3단계' 짧은 안내를 둔다.
   - 묻기 → 답과 근거 확인 → 틀리면 오류 신고
5. **검증 숫자 6칸**
   - 직원 화면에서는 한 줄 요약 + '검증 방법 보기'(접힘)로 줄인다.
   - 관리자용 숫자는 지금처럼 주소 끝 `#review`로 열 때 보인다.
6. **막히면**: 화면 아래쪽에 "답을 못 찾으면 → 담당부서" 자리를 둔다. 운영부서가 정해지면 연락처를 채운다.

완료 기준: 직원 3~5명에게 첫 화면만 5초 보여 주고 "여기서 무엇을 할 수 있나요?"라고 물었을 때, 대부분이 "내규를 물어볼 수 있다, 출장비·휴가 같은 것"이라고 답한다.

### ③ 답 화면 다듬기 (하루~이틀)

1. **위계**
   - 제목 → **한 줄 결론**(카드의 summary를 굵게) → 본문 → 핵심 정리 표 → 계산기 → 함께 보면 좋은 내용
   - 지금은 결론이 본문 속에 묻혀 있다.
2. **핵심 정리 표**: 휴대폰 폭에서는 2칸 표 대신 카드형으로 바꾼다(항목 이름 위, 값과 근거 아래).
3. **근거 조문 버튼**: "원문 보기"라는 뜻이 드러나게 한다(앞에 작은 문서 아이콘을 인라인 SVG로 붙이거나 이름표 추가). 대비와 크기는 ①에서 맞춘다.
4. **검수 상태 배지**: 누르면 뜻을 풀어 주는 짧은 설명을 연다(마우스를 올려야만 보이는 방식은 쓰지 않는다).
5. **계산기**
   - 합계 금액이나 핵심 날짜를 크게 강조한다.
   - '참고용'의 뜻을 한 줄로 단다("실제 지급·승인은 담당부서 기준").
   - 결과 복사 버튼은 담당부서 검수 뒤로 미룬다(자문단 권고).
6. **원문 판(휴대폰)**
   - 닫기 버튼은 44px로 한다.
   - 판 안에서 스크롤할 때 뒤 화면이 같이 움직이지 않게 한다(`overscroll-behavior: contain`).
   - 판이 열린 동안에는 키보드 초점이 판 안에 머물게 한다.

### ④ 점검과 측정 (반나절 + 사람)

1. **자동 점검(ui_test.js)에 추가**
   - 색 토큰 대비 계산(밝은·어두운 화면)
   - 버튼 최소 높이, 12px 미만 글씨 0개
   - 375 / 768 / 1024 / 1440px 폭에서 옆으로 넘치지 않음
2. **캡처 확인**: 밝은·어두운 화면, 확대 200%, 휴대폰 폭
3. **사람 확인**
   - 직원 5초 테스트(②)
   - 폐쇄망 저사양 PC에서 첫 화면이 뜨기까지의 시간(목표 5초 이내, 넘으면 글꼴 굵기를 4가지에서 2가지로 줄인다)

## 4. 하지 않을 것

- 외부 글꼴·스크립트·이미지 호출(폐쇄망, CSP)
- 이모지를 아이콘으로 쓰기. 아이콘이 꼭 필요하면 같은 모양 계열의 인라인 SVG 몇 개만 쓴다.
- 0.2초가 넘는 움직임, 화면 전체가 미끄러지는 효과
- 색만으로 상태 알리기(배지에는 항상 글자를 넣는다)
- 답 내용, 근거, 검색 방식, 계산 규칙을 바꾸기(이 계획은 겉모양과 쓰기 편함만 다룬다)
- 파일 크기를 200KB 넘게 늘리기

## 6. 정해 주셔야 할 것

1. **색**: 지금 초록 계열을 유지할지, 기관(우체국금융개발원) 대표 색으로 바꿀지. 바꾼다면 기관 CI 색 값을 받아야 한다.
2. **분야 메뉴**: 시범 분야('출산·육아', '복무(휴가)')를 '자주 찾는 분야'로 합칠지.
3. **오른쪽 원문 칸**: 처음에 접어 둘지(권장), 사용법 안내로 채울지.
4. **검증 숫자**: 직원 화면에서 한 줄 요약으로 줄일지(권장), 지금처럼 다 보일지.
