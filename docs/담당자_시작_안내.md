# 담당자 시작 안내 (처음 한 번만)

내규챗봇은 **GitHub**(내규 파일과 프로그램을 보관하는 사이트)와 **Claude 웹**(AI에게 일을 시키는 사이트) 두 곳에서 관리합니다. 컴퓨터에 설치할 것은 없습니다. 인터넷이 되는 PC(외부망)에서 웹 브라우저로 하면 됩니다.

GitHub 화면은 영어입니다. 아래에 **눌러야 할 영어 버튼 이름**을 그대로 적었습니다. 화면 모양이 조금 달라도 같은 이름의 버튼을 찾으면 됩니다.

## 먼저 확인하세요

- 외부망 PC에서 `github.com` 과 `claude.ai/code` 두 주소가 열리는지 봅니다. 안 열리면 정보보안 담당에게 열어 달라고 요청해야 합니다. 이 방식의 전제입니다.
- Claude 유료 계정(Pro)이 필요합니다.

## 1. GitHub 초대 받기

1. 인계해 주는 분이 내 GitHub 아이디로 초대를 보냅니다. GitHub 계정이 없으면 `github.com` 에서 `Sign up` 으로 만듭니다(받는 메일 주소는 자주 확인하는 것으로).
2. 메일에 "invited you to collaborate" 비슷한 제목의 메일이 옵니다. 열어서 `Accept invitation` 을 누릅니다.
3. 저장소 화면(`github.com/…/naegyu-chatbot`, 정확한 주소는 인계해 주는 분이 알려 줍니다)이 열리면 끝입니다. 주소를 즐겨찾기에 넣어 둡니다.

## 2. 메일 알림 켜기

내규가 바뀐 것 같을 때 GitHub 가 메일로 알려 줍니다. 꼭 켜 둡니다.

1. 저장소 화면 오른쪽 위의 `Watch` 를 누르고 `All Activity` 를 고릅니다.
2. 오른쪽 위 내 사진 → `Settings` → 왼쪽 `Notifications` 에서 `Email` 이 켜져 있고 받는 주소가 맞는지 봅니다.
3. 회사 메일로 받는다면 스팸함에도 들어오는지 한 번 확인합니다.
4. 인계해 주는 분이 저장소 변수 `NAEGYU_ASSIGNEES` 에 내 GitHub 아이디를 넣어 두면, 새 알림 글이 나에게 지정되어 메일이 옵니다(`docs/유지보수_안내.md` 참고).

## 3. Claude 웹 준비

1. `claude.ai/code` 에 접속해 Claude 계정으로 로그인합니다.
2. GitHub 와 연결하라는 안내가 나오면 따릅니다(GitHub 연결 버튼, 이어서 GitHub 쪽 허용 화면의 `Authorize`/`Install`). 연결할 저장소로 `naegyu-chatbot` 을 고릅니다.
3. 저장소를 고르고 "안녕, 이 저장소에 뭐가 있는지 알려 줘"라고 말해 봅니다. 대답이 오면 준비가 된 것입니다.

연결이 안 되거나 저장소가 안 보이면, GitHub 초대를 먼저 수락했는지 확인하고 인계해 주는 분에게 알립니다.

## 4. 연습: 시험 알림 하나 따라 해 보기

인계해 주는 분이 **시험 알림 글**(이슈) 하나를 만들어 둡니다. 실제 일처럼 한 번 해 봅니다.

1. 저장소 화면 위쪽 `Issues` 를 눌러 시험 알림 글을 엽니다. 무엇이 달라졌는지, 어디에 파일을 받아 뒀는지 적혀 있습니다.
2. `claude.ai/code` 에서 저장소를 열고 "내규 개정 반영"이라고 말합니다. Claude 가 한 단계씩 설명하고 다음에 할 말을 알려 줍니다. 그대로 따라 합니다.
3. 끝나면 Claude 가 **Pull Request**(바뀐 내용을 합쳐 달라는 요청서)를 엽니다. Claude 가 열지 못하면 요청서 글을 대화에 써 주고 눌러야 할 버튼을 알려 줍니다(`Create PR` 또는 GitHub 의 `Compare & pull request`).
4. GitHub 에서 그 Pull Request 를 엽니다.
   - 아래쪽에 초록색 체크 표시와 "All checks have passed"가 보이는지 봅니다. 빨간색이면 합치지 말고 Claude 웹에 그 글을 보여 줍니다.
   - 바뀐 내용을 읽고 맞으면 초록 `Merge pull request` → `Confirm merge` 를 누릅니다.
5. 합치면 몇 분 뒤 새 판이 만들어집니다. 저장소 화면 오른쪽의 `Releases` 에서 확인합니다.

연습이 끝나면 인계해 주는 분이 시험 글을 정리합니다.

## 5. 매주 할 일

- 월요일 오전에 `매주 확인 기록` 글에 댓글이 달리고 메일이 옵니다. 변동이 없으면 "이번 주 변동 없음"입니다.
- 내규가 바뀐 것 같으면 알림 글이 따로 만들어져 메일이 옵니다. 그때는 `docs/유지보수_안내.md` 를 봅니다.
- **메일이 한 주 동안 하나도 안 오면** 확인이 멈춘 것일 수 있습니다. `docs/유지보수_안내.md` 의 "메일이 안 올 때"를 봅니다.
